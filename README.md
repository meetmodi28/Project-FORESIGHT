# Inventory Forecasting & Analytics Dashboard 📊

An end-to-end data analytics and business intelligence project designed to predict inventory requirements and visualize stock performance. This repository contains the data processing scripts and the final reporting assets developed during a focused 3-day development sprint.

## 📑 Project Overview
Effective inventory management requires accurate forecasting and clear visibility into current stock levels. This project tackles those challenges by combining programmatic exploratory data analysis (EDA) with a robust, multi-page business intelligence solution. 

The workflow is split into two main phases:
1. **Data Preparation & EDA:** Conducted in Google Colab using Python to clean, structure, and model the raw inventory data.
2. **Data Visualization:** A comprehensive 12-page Microsoft Power BI dashboard built to present historical trends, actionable forecasting metrics, and high-level summaries for stakeholders.

## 🛠️ Tech Stack
* **Exploratory Data Analysis:** Python, Pandas, NumPy (via Google Colab)
* **Data Visualization & Modeling:** Microsoft Power BI, DAX
* **Version Control:** Git & GitHub
